# 中文内链规划

为中文文章提供少而精、可直接执行且可核查的链接建议。不要为了增加链接数量牺牲相关性或阅读体验。

## 确认范围

1. 阅读完整正文，识别主关键词、搜索意图、内容层级和目标读者。
2. 明确文章来源范围、语言范围和链接域名。用户要求只抓中文时，仅保留中文标题且正文实际可访问的中文页面；排除英文、其他语言以及会跳转到非中文版本的页面。
3. 若用户要求“全部文章”，覆盖全部分页或站点地图，采集并去重标题、摘要和规范 URL。不要只用站内搜索或搜索引擎结果代替全集抓取。
4. 打开候选页面核验实际内容、语言、页面用途和 URL 可访问性。

## 筛选正文内链

1. 仅保留与当前段落意图高度一致的文章。排除只是同属一个宽泛主题的页面。
2. 优先使用正文现有的准确、高搜索价值词组作为锚文本，不增加“点击查看”“了解更多”等引导句。
3. 锚文本应明确描述目标页主题，通常使用产品名、功能名、问题型关键词或完整搜索词组。
4. 如果现有词组含义模糊、过短或搜索价值不足，给出不改变原意的最小修改，并展示修改后的可锚定文本。
5. 同一关键词不要在近距离重复链接到不同页面。控制整体密度，优先保留最能补充当前内容的链接。

## 筛选品牌转化链接

1. 从文章已有商业语境出发寻找转化机会，不局限于官网、注册页、登录页、操作页、功能页或解决方案页。
2. 只有当目标页能直接承接该段需求时才推荐，例如：群发需求链接群发功能页，API 接入需求链接集成页，多客服需求链接协作或会话分配页。
3. 转化链接也必须锚定正文中准确或有搜索价值的文本；不满足时给出最小改写建议。
4. 避免把纯概念介绍过早链接到销售页。概念阶段优先知识文章，出现工具选择、接入、试用、操作或团队落地意图时再放转化链接。
5. 控制商业链接数量，避免多个链接承接相同产品能力。

## 选择延伸阅读

严格按以下顺序执行：

1. 先独立分析读者读完正文后可能继续搜索或解决的问题。
2. 再从已抓取的中文文章全集中寻找能回答这些问题的页面。
3. 不根据现有文章反向拼凑读者需求。
4. 延伸阅读无需锚定正文文本，直接提供文章标题和可访问 URL。
5. 若某篇文章已经作为正文内链使用，明确标注，方便用户避免重复。
6. 只保留与本文自然形成下一步阅读关系的文章；宁缺毋滥。

## 输出格式

将正文内链、品牌转化链接和延伸阅读放在同一个 Markdown 表格中，使用这些列：

| 类型 | 读者需求/推荐目的 | 目标页面或文章 | 来源网址 | 正文位置 | 当前可锚定文本 | 修改后锚文本（如需） | 修改建议 | 相关性 | 是否已用于正文内链 |
|---|---|---|---|---|---|---|---|---|---|

遵守以下填写规则：

- 来源网址使用可直接打开的 Markdown 链接。
- 正文位置写明章节、段落或可定位的原句。
- 不需要修改时填写“无需修改”。
- 延伸阅读的正文位置和锚文本相关列填写“不适用”。
- 相关性只输出高等级结果，如“极强”；不要用表格容纳一般相关候选。
- “是否已用于正文内链”对延伸阅读标注“是/否”；对转化链接可标注“否（转化链接）”。
- 表格前可简述抓取数量、语言过滤和去重情况；表格后只补充必要的密度或冲突说明。

## 最终检查

提交前确认：

- 已覆盖用户指定的全部中文文章来源，而非抽样搜索。
- 每个 URL 可访问且页面语言正确。
- 每个正文链接都有可定位的原文锚点或明确的最小修改方案。
- 每个转化页与当前段落的商业意图直接匹配。
- 延伸阅读由读者后续问题驱动。
- 没有弱相关、重复或为凑数量而加入的链接。
